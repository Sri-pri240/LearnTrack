# JVM Architecture Basics

### JDK vs JRE vs JVM
- **JDK (Java Development Kit):** Tools like compiler (`javac`) and debugger needed to write Java programs.
- **JRE (Java Runtime Environment):** Libraries and software framework needed to run Java programs.
- **JVM (Java Virtual Machine):** The engine that executes Java bytecode instructions line by line.

### Bytecode and WORA
- **Bytecode:** The intermediate system instruction format generated by the Java compiler.
- **Write Once, Run Anywhere (WORA):** Since the compiler outputs platform-independent bytecode, the same compiled program can run on any device with a compatible JVM installed.
